# Dharani V — Portfolio

Create React App + TypeScript portfolio.

## Run

```bash
npm install
npm start
```

## Structure

- `src/pages/` — page-level entry wrappers
- `src/components/sections/` — reusable section UI
- `src/components/layout/` — header, menu, footer and ambient UI
- `src/components/common/` — shared UI primitives
- `src/data/` — profile, navigation, projects, skills, research and credentials
- `src/styles/` — modular styles
- `src/hooks/` — scroll, active-section and UI hooks
- `public/assets/` — static portfolio assets

## UX

Desktop Selected Work uses the mouse wheel to move projects horizontally. At the beginning/end of the carousel, normal vertical page scrolling resumes. The right rail, previous/next control, keyboard arrows/PageUp/PageDown, smooth section navigation and floating quick actions provide multiple navigation paths.
